# weekly-review

The Monday review, written to drafts/: the law and the award, open visits, clients, contract changes, hours against price, thinnest margins and money, then the whole attention list.

Run `node scripts/cleaning.mjs weekly-review`. Add `--json` when you need every field. Resolve the site, cleaner, visit or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Read the draft back in five lines.
