# unassign

Take a cleaner off a visit and open it again.

Run `node scripts/cleaning.mjs unassign <visit> --reason="..." --actor="<name>"`. Add `--json` when you need every field. Resolve the site, cleaner, visit or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
