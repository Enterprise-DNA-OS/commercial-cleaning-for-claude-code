# invoices

Every invoice with where it stands: not sent, sent, overdue, paid.

Run `node scripts/cleaning.mjs invoices`. Add `--json` when you need every field. Resolve the site, cleaner, visit or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
