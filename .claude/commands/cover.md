# cover

Who can take a visit: every active cleaner in the same country checked against the award, double bookings, police vetting, site induction and weekly hours. Cleaners who know the site first, then fewest hours. Changes nothing.

Run `node scripts/cleaning.mjs cover <visit>`. Add `--json` when you need every field. Resolve the site, cleaner, visit or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Recommend the first 'can do it'. Explain any 'needs a reason' line in plain words. Never fill it without the operator's yes.
