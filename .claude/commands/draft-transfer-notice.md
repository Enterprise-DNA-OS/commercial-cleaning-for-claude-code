# draft-transfer-notice

For a New Zealand site we are losing: a notice to each cleaner of their right to elect to transfer to the incoming contractor (ERA 2000 s 69G, s 69I). Written to drafts/.

Run `node scripts/cleaning.mjs draft-transfer-notice <site>`. Add `--json` when you need every field. Resolve the site, cleaner, visit or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Point out the notice date. Ask the operator to have it checked by someone who knows employment law. Never send it.
