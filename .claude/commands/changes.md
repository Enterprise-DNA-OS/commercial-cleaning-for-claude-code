# changes

Sites changing hands: losing to another contractor or winning from one, the date, the New Zealand notice date for the cleaners' right to transfer, and where each stands.

Run `node scripts/cleaning.mjs changes`. Add `--json` when you need every field. Resolve the site, cleaner, visit or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

For a New Zealand site we are losing, the cleaners must be told 20 working days before (ERA 2000 s 69G). Offer `/draft-transfer-notice`.
