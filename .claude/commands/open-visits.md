# open-visits

Visits with nobody on them in the next 14 days (or --days).

Run `node scripts/cleaning.mjs open-visits [--days=14]`. Add `--json` when you need every field. Resolve the site, cleaner, visit or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

For each, offer to run `/cover`.
