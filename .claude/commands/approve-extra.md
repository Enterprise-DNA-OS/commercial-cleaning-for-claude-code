# approve-extra

Record the client's yes to an extra.

Run `node scripts/cleaning.mjs approve-extra <X-ref> --by="<who said yes>" [--date=YYYY-MM-DD] --actor="<name>"`. Add `--json` when you need every field. Resolve the site, cleaner, visit or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
