# return-key

A key comes back to the office.

Run `node scripts/cleaning.mjs return-key <site> --label="<label>" --actor="<name>"`. Add `--json` when you need every field. Resolve the site, cleaner, visit or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
