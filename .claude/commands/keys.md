# keys

The key and access register: every key, card, fob and alarm code, who holds it, and whether that person has left.

Run `node scripts/cleaning.mjs keys`. Add `--json` when you need every field. Resolve the site, cleaner, visit or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Keys held by someone who has left come first: offer `/return-key`.
