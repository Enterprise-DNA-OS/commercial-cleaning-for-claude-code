# cleaners

Every cleaner with employment type, award level, status, police vet date, the sites they are inducted at and keys held.

Run `node scripts/cleaning.mjs cleaners`. Add `--json` when you need every field. Resolve the site, cleaner, visit or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
