# respond

Record that the client has had a reply.

Run `node scripts/cleaning.mjs respond <CMP-ref> [--at="YYYY-MM-DD HH:MM"] [--note="..."] --actor="<name>"`. Add `--json` when you need every field. Resolve the site, cleaner, visit or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
