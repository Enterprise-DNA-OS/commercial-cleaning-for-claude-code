# add-cleaner

Add a cleaner.

Run `node scripts/cleaning.mjs add-cleaner --code=<CODE> --name="<name>" [--employment=full-time|part-time|casual] [--level=1|2|3] [--pay=<hourly rate before loadings>] [--vetted=YYYY-MM-DD] [--phone=] [--email=] --actor="<name>"`. Add `--json` when you need every field. Resolve the site, cleaner, visit or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

In Australia, record the award level: the pay check uses it.
