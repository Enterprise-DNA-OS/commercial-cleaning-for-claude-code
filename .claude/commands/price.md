# price

Price a site from its scope of works: weekly hours, labour a month and the monthly fee at the target margin. Works on a prospect too.

Run `node scripts/cleaning.mjs price <site>`. Add `--json` when you need every field. Resolve the site, cleaner, visit or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Compare with the current fee. Say what drives the number (the daily tasks, usually).
