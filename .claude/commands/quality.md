# quality

Every site's last inspection, score, 90-day average, open faults and complaints.

Run `node scripts/cleaning.mjs quality`. Add `--json` when you need every field. Resolve the site, cleaner, visit or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Sites under the pass mark or overdue an inspection first.
