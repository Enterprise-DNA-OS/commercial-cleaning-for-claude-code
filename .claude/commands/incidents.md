# incidents

Every incident, newest first, with where it stands: regulator not notified, client not told, open, closed.

Run `node scripts/cleaning.mjs incidents`. Add `--json` when you need every field. Resolve the site, cleaner, visit or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
