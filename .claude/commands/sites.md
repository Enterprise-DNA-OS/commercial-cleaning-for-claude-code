# sites

Every site with its client, fee, priced hours, contract dates and whether it needs police vetting.

Run `node scripts/cleaning.mjs sites`. Add `--json` when you need every field. Resolve the site, cleaner, visit or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
