# complaints

Open complaints, newest first, with hours to reply and where each stands. --all adds the resolved ones.

Run `node scripts/cleaning.mjs complaints [--all]`. Add `--json` when you need every field. Resolve the site, cleaner, visit or client by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

No reply and late first.
